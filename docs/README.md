# Documentation Index

Use this folder for detailed guides on running experiments, understanding compressor behavior, and visualizing results.

- `docs/examples.md`: run commands and output paths for scripts under `example/`
- `docs/compressors.md`: what each compressor means and how each config works
- `docs/scripts.md`: pre-built plotting scripts and their expected CSV format
- `docs/evaluation.md`: what `eval_ppl.py` does and how `eval_ppl_residual_path_for_qwen3.py` differs

Suggested reading order for new users:

1. `docs/examples.md`
2. `docs/compressors.md`
3. `docs/evaluation.md`
4. `docs/scripts.md`
